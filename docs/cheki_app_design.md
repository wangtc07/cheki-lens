# ChekiLens (拍立得智慧掃描與透視校正 App) - 設計定義文件

> **版本**：v1.0 (Settled)  
> **狀態**：核心架構決策敲定 (Ready for Architecture & Implementation)  
> **核心代碼來源**：`src/image_process/cheki_crop.py`  
> **平台**：iOS 原生 (100% On-Device, Swift / SwiftUI)

---

## 1. 專案願景與定位

* **定位**：專為實體拍立得（Instax Mini / Square / Wide）設計的高精度翻拍、透視校正與典藏工具。
* **核心標語**：隨手一拍，精準拉直，完整保留實體拍立得的底片質感與手寫筆跡。
* **商業模式**：免費下載 + 增值小額買斷 (Freemium with Lifetime Unlock)
  * **免費版**：低解析度匯出 + 拍立得右下角自帶簡約「Scanned with ChekiLens」浮水印；每日贈送 1 張高解析度無浮水印額度。
  * **Pro 買斷版 (小額 NT$ 90 ~ 150 / US$ 2.99 ~ 4.99)**：終身解鎖「4K 高解析度無損匯出」、「無浮水印」、「多圖批次自動處理佇列」。

---

## 2. 目標用戶群與核心痛點

1. **地下偶像 / 粉絲追星族群**：
   * 痛點：去見面會拍的チェキ（拍立得），現場燈光混亂、手拿拍照容易有反光與透視傾斜，發 X (Twitter) / IG 很難拍得端正。
2. **底片 / 拍立得攝影玩家**：
   * 痛點：傳統文件掃描軟體（如 CamScanner）會把白邊全裁掉，並強制銳化黑白反差，破壞底片溫潤色彩；平板掃描機又太麻煩。
3. **拍立得手帳記錄者**：
   * 痛點：底部有重要日期、簽名或塗鴉，一般修圖軟體無法快速鎖定標準 86mm × 54mm 比例拉直。

## 3. 功能規格（已敲定之設計決策）

### 3.1 核心偵測與規格涵蓋
* **相紙規格涵蓋**：
  * **Auto（自動識別）**：利用 Vision 辨識幾何邊界，依長寬比自動落入對應規格。
  * **Instax Mini**：86mm × 54mm (比例 ≈ 1.593)
  * **Instax Square**：86mm × 72mm (比例 ≈ 1.194)
  * **Instax Wide**：86mm × 108mm (比例 ≈ 1.256 橫向)
* **多層 fallback 邊框偵測**：
  1. **Apple Vision 原生矩形辨識** (`VNDetectRectanglesRequest`)
  2. **邊緣 Hough 直線交叉偵測**
  3. **白色邊框色相分割 (HSV/RGB Mask)**
* **互動式手動微調 (Interactive Adjustment)**：
  * 支援四角放大鏡錨點拖曳（Magnifying Loupe Drag），手指按壓角落時浮出放大鏡精確吸附相紙邊角。

### 3.2 拍攝與匯入工作流 (Dual Workflow)
* **相簿批次匯入 (Phase 1 MVP 核心)**：支援從相簿一次選擇任意數量的拍立得翻拍照（不設上限），以背景工作緒排隊並行處理，全程不阻塞 UI 操作。
* **即時相機掃描 (Phase 2 疊加)**：AVFoundation 即時取景，畫面浮出引導邊框，對準自動捕捉。

### 3.3 反光與光影處理機制 (Dual Anti-Glare Pipeline)
* **預設單張即時模式 (Mode A - 速度與直覺優先)**：
  * 相機取景時，以視覺亮斑演算法偵測相紙膜上的過曝區域，即時提示「請微調手機傾角避開頂光」。
  * 結合 Core Image 高光補償與動態範圍平衡濾鏡，有效壓制輕微反光並保留細節。
* **可選多張合成去反光 (Mode B - 極致畫質優先)**：
  * 用戶可切換「去反光合成模式」，引導以兩個略微不同的傾斜角度拍攝兩張照片。
  * 原生演算法自動進行特徵點配準（Feature Matching & Homography），偵測反光區域並以無反光角度的像素進行融合替換，完美消除白斑。

### 3.4 輸出與邊界偏移微調 (Border Margin Offset)
* **純卡片輸出格式**：
  * 專注輸出乾淨端正的標準比例拍立得卡片（JPEG / PNG），長邊達 4K 典藏級解析度（3840px）。
* **內外邊界自訂偏移滑桿 (Margin Offset - Inset / Outset)**：
  * 解決邊界辨識的個人偏好差異：
    * **向外偏移 (Outset, +1% ~ +3%)**：將四角錨點稍微往外擴展，確保 100% 完整保留相紙最外緣與底片包邊，絕不裁切任何邊界。
    * **向內偏移 (Inset, -1% ~ -3%)**：將邊界略微往內收窄，修除翻拍時背景或邊緣微小陰影，輸出最純粹俐落的相紙實體感。

### 3.5 推活典藏與手寫日期 OCR (Oshi-katsu & Date OCR)
* **階層分類**：
  * 建立「團體 ➔ 成員」管理體系。
* **底部手寫日期 OCR (`VNRecognizeTextRequest`)**：
  * 精確掃描拍立得底部白色留白區的手寫文字，支援常見格式（如 `24.9.24`, `2024/9/24`, `9/24`）。
  * 提取日期並自動校正數位照片的真實拍攝時間（`creationDate`）。

### 3.6 批次匯入與正反面配對機制 (Batch Import & Pairing Workbench)
* **相簿選取後的確認工作台**：
  * 在執行批次處理前，提供三種彈性配對模式，支援「部分單面、部分雙面」的混合批次：
    1. **【直接執行】**：全部照片作為獨立正面卡片處理。
    2. **【自動配對 (依序 + Vision 驗證)】**：按選取順序自動兩兩配對；利用 Vision 視覺特徵進行防呆校驗（正面相紙窗 vs 背面深色/印字），若偵測異常（如連續兩張正面）主動彈出提示確認。
    3. **【手動配對】**：視覺化網格互動，以「先點正面、再點反面」的循環手勢進行直覺綁定，未配對者自動作為單面正面保存。

### 3.7 備忘錄與標記 (#) 設計（嚴格遵循 Apple 原生 HIG）
* **設計風格**：
  * 100% 採用 Apple 官方原生套件與設計規範，完全捨棄無必要的擬真音效與紙質材質，保持極簡、高響應度與現代感。
* **操作與查看流程（仿 iOS 原廠「照片 App」Info Sheet）**：
  * **一覽檢視**：以系統標準網格（Grid）瀏覽照片。
  * **單張檢視與上滑互動**：
    * 點選進入單張照片全螢幕檢視。
    * **未有備忘時**：向上滑動（Swipe Up）或點擊右上角「新增備忘」，圖片等比縮小上移，下方滑出原生編輯面板，提供「文字輸入框」與「# 標記輸入框」；直接使用系統鍵盤（內建聽寫即可滿足語音需求）。
    * **已有備忘時**：向上滑動（Swipe Up）直接瀏覽完整的相片資訊（手寫日期、#標籤、對話筆記），與 iOS 系統照片查看資訊的體驗完全一致。

### 3.8 系統相簿雙向同步 (Q2 - B 模式)
* **正反面雙圖寫回相簿**：
  * 正面與背面分別作為獨立兩張相片寫入 iOS 原生相簿（`ChekiLens/[團體]/[成員]`）。
  * 正反兩張照片的 `creationDate` 統一設定為 OCR 識別的手寫拍攝時間，在相簿時間軸中緊密相鄰、不被打散。
  * 背面照片的 Metadata / 備註欄位寫入備忘錄文字與 # 標記。

## 4. 系統架構與技術棧

* **UI**：SwiftUI (標準 NavigationStack, PhotosPicker, 系統原生 Sheet, ContextMenu)
* **圖像與文字運算**：Apple Vision Framework (`VNDetectRectanglesRequest`, `VNRecognizeTextRequest`) + Core Image (`CIPerspectiveCorrection`)
* **相簿與儲存**：Photos framework (`PHPhotoLibrary`, `PHAssetCreationRequest`)
* **內購系統**：StoreKit 2 (Non-Consumable Lifetime Purchase, 零伺服器驗證)
* **離線架構**：100% 本機執行，無任何後端 API 依賴。
