# wbg.py 照片處理工具使用說明書

## 功能概述

`wbg.py` 是一個智能照片處理工具，專門用於為照片添加白色背景邊框、讀取相機和鏡頭信息，並在照片上添加專業的相機/鏡頭文字標記。

## 主要功能

### 1. 自動白邊處理
- 將照片調整為 3000×3000 像素的正方形格式
- 自動添加 240 像素寬度的白色邊框
- 保持原照片比例並居中放置

### 2. EXIF 數據讀取
- 自動讀取照片的相機品牌和型號
- 讀取鏡頭品牌、型號和焦距信息
- 智能識別光圈值有效性

### 3. 文字標記添加
- 在照片底部中央添加相機/鏡頭信息
- 使用專業字體：SF Mono Medium Italic (44號)
- 文字顏色：深灰色 (5,5,5)
- 位置：離底部 50 像素

### 4. 智能跳過功能
- 自動檢測已處理過的照片
- 基於照片尺寸和白色邊框特徵判斷
- 避免重複處理，提高效率

### 5. 手動鏡頭選擇
- 當 EXIF 數據不完整時支持手動選擇
- 預設兩個鏡頭選項：
  - HELIOS 44M-5 MC 58mm f/2
  - 7Artisans 7.5mm F2.8

## 命令行參數與簡化縮寫

`wbg.py` 支援 1~2 字元的簡化短參數，並完全保留原本的長參數名稱：

| 縮寫 (1~2字) | 完整參數 | 說明 | 範例 |
| :--- | :--- | :--- | :--- |
| `-t` / `-tx` | `--add-text` | 增加相機與鏡頭 EXIF 文字 | `python wbg.py -t` |
| `-p` / `-pf` | `--pick-files` | 用原生檔案視窗多選圖片處理 | `python wbg.py -p` |
| `-a` / `-ar` | `--aspect` | 成品畫布比例 (auto, square, 1:1, 4:3, 16:9) | `python wbg.py -a 4:3` |
| `-b` / `-br` | `--border-ratio` | 白邊佔比 (0~1, 預設 0.16) | `python wbg.py -b 0.1` |
| `-e` / `-be` | `--border-equal` | 四邊白邊等寬 (依長邊比例計算) | `python wbg.py -e` |
| `-H` / `-mh` | `--manual-help` | 顯示詳細使用手冊說明 | `python wbg.py -H` |
| `-v` | `--version` | 顯示版本資訊 | `python wbg.py -v` |

## 使用流程

### 1. 選擇資料夾
- **輸入資料夾**：選擇包含原始照片的資料夾
- **輸出資料夾**：選擇處理後照片的儲存位置

### 2. 鏡頭設定
程序會詢問鏡頭設定方式：

**選項 1：預設鏡頭（推薦）**
- 適用於批量處理相同鏡頭的照片
- 只需選擇一次，所有照片都會使用相同鏡頭
- 提高處理效率

**選項 2：手動選擇**
- 每張照片都會提示選擇鏡頭
- 適用於混合使用不同鏡頭的照片

### 3. 鏡頭選擇
如果選擇預設鏡頭，會顯示兩個選項：
```
1. HELIOS 44M-5 MC 58mm f/2
2. 7Artisans 7.5mm F2.8
```

### 4. 自動處理
程序會自動處理所有照片，並顯示進度信息：
```
處理 photo1.jpg: Canon EOS R5 / RF24-70mm F2.8L IS USM
跳過 photo2.jpg：照片已經被處理過（包含白邊）
處理 photo3.jpg: Sony α7R IV / 50mm
```

## 輸出規格

### 照片規格
- **尺寸**：3000×3000 像素
- **格式**：保持原始格式（JPEG/PNG等）
- **白邊**：240 像素寬度
- **質量**：保持原始質量

### 文字規格
- **字體**：SF Mono Medium Italic (44號)
- **備用字體**：Georgia → Arial → 系統默認
- **顏色**：深灰色 (5,5,5)
- **位置**：底部中央，離底部 50 像素
- **格式**：`{相機型號} / {鏡頭型號}`

## 支持格式

### 輸入格式
- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif)
- BMP (.bmp)

### 輸出格式
- 保持原始格式
- 自動優化文件大小

## 智能功能

### EXIF 數據處理
- **完整信息**：直接使用相機和鏡頭信息
- **部分信息**：組合可用信息（如焦距）
- **無效光圈**：識別 "f/--" 並觸發手動選擇
- **無信息**：提示手動選擇鏡頭

### 已處理照片檢測
程序會檢查以下特徵來識別已處理照片：
- 照片尺寸是否為 3000×3000
- 四個角落是否為白色（RGB ≥ 250）
- 綜合判斷是否為已處理照片

### 錯誤處理
- 自動跳過無法讀取的照片
- 提供詳細的錯誤信息
- 繼續處理其他照片

## 故障排除

### 常見問題

**Q: 無法讀取 EXIF 數據**
A: 某些照片可能沒有 EXIF 數據，程序會提示手動選擇鏡頭。

**Q: 字體顯示異常**
A: 程序會自動嘗試多種字體，如果都有問題，會使用系統默認字體。

**Q: 處理速度慢**
A: 建議使用預設鏡頭選項，避免每張照片都手動選擇。

**Q: 照片質量下降**
A: 程序保持原始照片質量，不會壓縮照片。

### 錯誤信息

- `無法讀取 {filename} 的EXIF數據`：照片可能損壞或沒有 EXIF 數據
- `跳過 {filename}：照片已經被處理過`：照片已包含白邊，正常跳過
- `請輸入有效的選項編號`：輸入了無效的選擇，請重新輸入
